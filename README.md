### About

Computer science student in Hyderabad, moving from web development into **AI and
machine learning engineering**. I came in through the MERN stack and I'm now
building the pieces of LLM systems from the ground up — retrieval, embeddings,
tool calling — as command-line tools, because a CLI forces you to understand the
pipeline instead of hiding it behind a framework.

- 🧠 Building **RAG and tool-calling systems** from first principles
- 🔨 Working through **PyTorch** and the maths underneath it
- 📚 Reading up on **transformers, embeddings, and vector search**
- 🤝 Open to collaborating on **anything ML or Python**
- 📫 Reach me at **nikhilbabu829@gmail.com**
